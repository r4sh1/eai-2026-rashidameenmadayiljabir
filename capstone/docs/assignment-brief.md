## Assignment details

| Item | Requirement |
|---|---|
| Kickoff | Session 8 — 11 November 2026, C113 |
| Deadline | 25 November 2026, 20:00 Europe/Riga |
| Weight | 50% of the final grade |
| Project type | Individual project; not a group project |
| Progression gate | Session 0 and PA1–PA7 must all have been submitted before their cut-offs for the capstone to be graded |
| Minimum capstone result | 41.0 points out of 115, after the late penalty and defence |
| Defence | Oral examination of approximately 20 minutes; pass/fail |

## Grading structure

The grading document specifies 115 total capstone points: 30 public-test points, 60 hidden-test points, 10 manual-review points and 15 points for the optional advanced Temporal component. The advanced component is all-or-nothing. A grade of 10 requires the advanced component; without it, the stated ceiling is grade 9.

The defence is a pass/fail gate. The grading document states that a failed defence results in zero capstone points. Both the homework average and capstone must pass independently, and the progression gate must be clear.

## Oral defence

The grading document describes an approximately 20-minute defence:

- **Explain (about 8 minutes):** explain the architecture using the project's diagrams, discuss an ADR selected by the examiner, and explain the code behind a selected pattern-table row.
- **Drill (about 10 minutes):** reproduce and diagnose a planted fault using the project's logs, trace, `/ops/metrics` and runbook.
- **Wrap (about 2 minutes):** discuss what would break first under ten times the load.

For the authoritative point breakdown, test criteria, late-penalty rules and defence conditions, consult [GRADING.md](../GRADING.md) and the repository [SYLLABUS.md](../../SYLLABUS.md).
